1. Click **Deploy** > **New deployment**.
2. Click the gear icon next to **Select type** and choose **Web app**.
3. Set **Execute as** to **Me**, so the script writes to the sheet with your
   access.
4. Set **Who has access** to **Anyone**. Cypress Cloud can't sign in to Google,
   so any other setting turns its deliveries away. The token from
   [Step 3](#Step-3-Store-a-token-that-authenticates-Cypress-Cloud) is what
   keeps other callers out.
5. Click **Deploy** and copy the **Web app** URL. It ends in `/exec`.

:::caution

**Publish a new version after every edit.** Deliveries run the version you
deployed, not the code in the editor, even after you save and run `setup`. If
new rows don't match the headers, the deployment is still on an older version.
Open **Deploy** > **Manage deployments**, edit this deployment, choose **New
version** under **Version**, and click **Deploy**. The URL stays the same, so
the Cypress Cloud webhook needs no change. **New deployment** creates a
different URL.

:::
