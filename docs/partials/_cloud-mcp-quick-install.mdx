VS Code and Claude Code can add the Cloud MCP server for you, with no
configuration file to edit. Both connect over OAuth, so your browser opens to a
Cypress Cloud sign-in the first time the server is used.

To add the server to Claude Code, run:

```bash
claude mcp add --transport http --scope user cypress-cloud https://mcp.cypress.io/mcp
```
