`.scrollTo()` scrolls a container, either the window or a scrollable element, to
a position. `.scrollIntoView()` scrolls whatever contains an element until that
element is in view. To reach a specific item, use `.scrollIntoView()` on the
item rather than `.scrollTo()` on its container.

```javascript
cy.get('#feed').scrollTo('bottom') // scrolls the container itself
cy.get('#item-5').scrollIntoView() // scrolls until this item is in view
```
