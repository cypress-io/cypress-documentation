# Cypress Plugins

import PluginsList from '@site/src/components/plugins-list'

Plugins extend and customize how you write, run, and report on your Cypress
tests. They add capabilities like bundling and preprocessors, custom commands,
network and API helpers, visual, accessibility, and AI-assisted testing, CI
integrations, and rich reporters. They're typically published as versioned npm
modules, so you can adopt and update them independently of Cypress itself.

The categories follow the path of a test suite: set up, write, run, check, and
report & ship. The Cypress team maintains the plugins it builds and lists them
first in each category. The company behind a product builds its vendor plugins,
and independent authors build community plugins. Cypress doesn't review vendor
or community plugins, so check a plugin's repository and recent releases before
you adopt it.

Built something useful?
[Submit your own plugin](https://github.com/cypress-io/cypress-documentation/blob/master/CONTRIBUTING.md#adding-plugins).

:::info

Check out our [How to use Plugins](/app/plugins/plugins-guide) or our
[Node Events Overview](/api/node-events/overview) for writing a plugin.

:::
