# Cypress Plugins

import PluginsList from '@site/src/components/plugins-list'

Cypress plugins add custom commands, preprocessors, visual and accessibility
testing, CI integrations, and reporters to your test suite. Most are npm
packages that you install and update separately from Cypress. Cypress doesn't
review vendor or community plugins, so check a plugin's repository and recent
releases before you adopt it.

Built something useful?
[Submit your own plugin](https://github.com/cypress-io/cypress-documentation/blob/master/CONTRIBUTING.md#adding-plugins).

<PluginsList />

Found something out of date or a plugin that should be added or removed?
[Open a pull request or issue](https://github.com/cypress-io/cypress-documentation/blob/master/CONTRIBUTING.md#adding-plugins).
