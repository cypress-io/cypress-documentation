# Vue API

The `cypress/vue` module provides the following methods and interfaces for mounting and testing Vue components.

## mount

```js
import { mount } from 'cypress/vue'
```

## Interfaces

### CyMountOptions

The options `mount` accepts: the
[Vue Test Utils mounting options](https://test-utils.vuejs.org/api/#mount), plus
Cypress's `log` option. `cypress/vue` exports the type, so a custom
`cy.mount()` command can type its options with it and add options of its own:

```ts
import { type CyMountOptions } from 'cypress/vue'
import { type Router } from 'vue-router'

type MountOptions = CyMountOptions<any> & { router?: Router }
```

See [Type custom `cy.mount()` options in Vue](/app/component-testing/vue/examples#Type-custom-cymount-options-in-Vue)
for why `CyMountOptions<any>` works where `Parameters<typeof mount>` doesn't.
