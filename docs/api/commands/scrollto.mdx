# scrollTo

Scroll to a specific position.

It is [unsafe](/app/core-concepts/retry-ability#Only-queries-are-retried) to
chain further commands that rely on the subject after `.scrollTo()`.

## Syntax

```javascript
cy.scrollTo(position)
cy.scrollTo(x, y)
cy.scrollTo(position, options)
cy.scrollTo(x, y, options)

  // ---or---

  .scrollTo(position)
  .scrollTo(x, y)
  .scrollTo(position, options)
  .scrollTo(x, y, options)
```

### Usage

<Icon name="check-circle" color="green" /> **Correct Usage**

```javascript
cy.scrollTo(0, 500) // Scroll the window 500px down
cy.get('.sidebar').scrollTo('bottom') // Scroll 'sidebar' to its bottom
```

<Icon name="exclamation-triangle" color="red" /> **Incorrect Usage**

```javascript
cy.title().scrollTo('My App') // Errors, 'title' does not yield DOM element
```

### Arguments

<Icon name="angle-right" /> **position _(String)_**

A specified position to scroll the window or element to. Valid positions are
`topLeft`, `top`, `topRight`, `left`, `center`, `right`, `bottomLeft`, `bottom`,
and `bottomRight`.

<DocsImage
  src="/img/api/scrollto/scroll-positions-diagram.svg"
  alt="Diagram of where each position moves the visible area within the scrollable content: topLeft, top, and topRight scroll to the top; left, center, and right to the middle; and bottomLeft, bottom, and bottomRight to the bottom. Each position scrolls both axes to 0, 50%, or 100% of the scrollable distance."
  noBorder
/>

<Icon name="angle-right" /> **x _(Number, String)_**

The distance in pixels from window/element's left or percentage of the
window/element's width to scroll to.

<Icon name="angle-right" /> **y _(Number, String)_**

The distance in pixels from window/element's top or percentage of the
window/element's height to scroll to.

<Icon name="angle-right" /> **options _(Object)_**

Pass in an options object to change the default behavior of `cy.scrollTo()`.

| Option             | Default                                                           | Description                                                                         |
| ------------------ | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `duration`         | `0`                                                               | Scrolls over the duration (in ms). Accepts a number or a numeric string.            |
| `easing`           | `swing`                                                           | Easing animation for the scroll. Accepts `swing` or `linear`.                       |
| `ensureScrollable` | `true`                                                            | Ensure element is scrollable. Error if element cannot scroll.                       |
| `log`              | `true`                                                            | Displays the command in the [Command log](/app/core-concepts/open-mode#Command-Log) |
| `timeout`          | [`defaultCommandTimeout`](/app/references/configuration#Timeouts) | Time to wait for `.scrollTo()` to resolve before [timing out](#Timeouts)            |

<HeaderYields />

- `.scrollTo()` yields the same subject it was given.
- `cy.scrollTo()` yields the `window` when it starts a chain.
- It is [unsafe](/app/core-concepts/retry-ability#Only-queries-are-retried)
  to chain further commands that rely on the subject after `.scrollTo()`.

## Examples

### Position

#### Scroll to the bottom of the window

```javascript
cy.scrollTo('bottom')
```

#### Scroll to the center of the list

```javascript
cy.get('#movies-list').scrollTo('center')
```

### Coordinates

#### Scroll 500px down the list

```javascript
cy.get('#infinite-scroll-list').scrollTo(0, 500)
```

#### Scroll the window 500px to the right

```javascript
cy.scrollTo('500px')
```

#### Scroll 25% down the element's height

```javascript
cy.get('.user-photo').scrollTo('0%', '25%')
```

### Options

#### Use linear easing animation to scroll

```javascript
cy.get('.documentation').scrollTo('top', { easing: 'linear' })
```

#### Scroll to the right over 2000ms

```javascript
cy.get('#slider').scrollTo('right', { duration: 2000 })
```

#### Do not error if element is not scrollable

Let's say we do not know whether our `table` element is scrollable. Sometimes
the `table` may be scrollable (with 2,000 rows) and sometimes the `table` may
not be scrollable (with 5 rows). You can ignore the error checking to ensure the
element is scrollable by passing `ensureScrollable: false`.

```js
// will move on to next command even if table is not scrollable
cy.get('table').scrollTo('bottom', { ensureScrollable: false })
cy.get('table').find('tr:last-child').should('be.visible')
```

### Workflows

#### Assert the scroll position after scrolling

`.scrollTo()` yields the window or element it scrolled, not the scroll position.
To check the position, query it after the scroll: `scrollY` on the window, or
`scrollTop` on an element.

```javascript
cy.scrollTo(0, 500)
cy.window().its('scrollY').should('equal', 500)

cy.get('#feed').scrollTo('bottom')
cy.get('#feed').invoke('scrollTop').should('be.gt', 0)
```

#### Load more items in an infinite scroll list

Scroll to the bottom of the list, then assert on the new item count. The
assertion retries until the next page of items renders.

```javascript
cy.get('#feed .item').should('have.length', 20)
cy.get('#feed').scrollTo('bottom')
cy.get('#feed .item').should('have.length.gt', 20)
```

#### Show a back-to-top button after scrolling

Some elements appear only once the page scrolls, such as a back-to-top button,
a sticky header, or a lazy-loaded image. Scroll first, then assert on the
element.

```javascript
cy.scrollTo('bottom')
cy.get('[data-cy="back-to-top"]').should('be.visible')
```

## Notes

### Actionability

`cy.scrollTo()` does not run the
[actionability](/app/core-concepts/interacting-with-elements) checks that
commands like [`.click()`](/api/commands/click) do. It scrolls an element even
when the element is hidden, disabled, or covered by another element. Before it
scrolls, `cy.scrollTo()` retries until the subject is attached to the DOM and is
scrollable. Pass `ensureScrollable: false` to skip the scrollable check.

### Scopes

`cy.scrollTo()` acts differently whether it's starting a series of commands or
being chained off of an existing one.

#### When starting a series of commands:

This scrolls the `window`.

```javascript
cy.scrollTo('bottom')
```

#### When chained to an existing series of commands:

This scrolls the `#checkout-items` element.

```javascript
cy.get('#checkout-items').scrollTo('right')
```

#### When chained off `cy.window()`:

This scrolls the `window`, the same as starting a series of commands.

```javascript
cy.window().scrollTo('bottom')
```

### Choosing between .scrollTo() and .scrollIntoView()

`.scrollTo()` scrolls a container, either the window or a scrollable element, to
a position. [`.scrollIntoView()`](/api/commands/scrollintoview) scrolls whatever
contains an element until that element is in view. To reach a specific item, use
`.scrollIntoView()` on the item rather than `.scrollTo()` on its container.

```javascript
cy.get('#feed').scrollTo('bottom') // scrolls the container itself
cy.contains('#feed .item', 'Item 5').scrollIntoView() // scrolls until this item is in view
```

Both commands scroll `#feed`. The difference is what you aim at, and where the
list ends up.

<DocsImage
  src="/img/api/scrollto/scrollto-vs-scrollintoview-diagram.svg"
  alt="Two views of the same eight-item #feed list. scrollTo('bottom') targets the container and shows items 6 to 8; scrollIntoView() on Item 5 targets the item and shows items 5 to 7, with Item 5 at the top."
  noBorder
/>

### Fixing the "element is not scrollable" error

`.scrollTo()` errors with `failed because this element is not scrollable` when
the element you target has no content overflowing it to scroll. This usually
means the scrolling happens on a different element, often the window, while the
targeted wrapper grows to fit its content. Target the element whose `overflow`
is `auto` or `scroll` instead, or scroll the window.

```javascript
// Errors: .page-wrapper grows with its content, so the window scrolls instead
cy.get('.page-wrapper').scrollTo('bottom')

// Scroll the window instead
cy.scrollTo('bottom')
```

Pass `ensureScrollable: false` only when an element is sometimes scrollable and
sometimes not, as in
[Do not error if element is not scrollable](#Do-not-error-if-element-is-not-scrollable).

## Rules

<HeaderRequirements />

- `.scrollTo()` requires being chained off a command that yields a DOM element
  or the `window`.
- `.scrollTo()` requires a single element. It errors when the subject contains
  more than one element.
- `.scrollTo()` requires the element to be scrollable, unless you pass
  `ensureScrollable: false`.

<HeaderTimeouts />

- `.scrollTo()` can time out waiting for the element to become scrollable.
- `.scrollTo()` can time out waiting for assertions you've added to pass.
