# focused

Get the DOM element that is currently focused.

## Syntax

```javascript
cy.focused()
cy.focused(options)
```

### Usage

<Icon name="check-circle" color="green" /> **Correct Usage**

```javascript
cy.focused() // Yields the element currently in focus
```

### Arguments

<Icon name="angle-right" /> **options _(Object)_**

Pass in an options object to change the default behavior of `cy.focused()`.

| Option    | Default                                                           | Description                                                                         |
| --------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `log`     | `true`                                                            | Displays the command in the [Command log](/app/core-concepts/open-mode#Command-Log) |
| `timeout` | [`defaultCommandTimeout`](/app/references/configuration#Timeouts) | Time to wait for `cy.focused()` to resolve before [timing out](#Timeouts)           |

<HeaderYields />

- `cy.focused()` yields the DOM element that currently has focus.
- When no element has focus and it's chained with `.should('not.exist')`,
  `cy.focused()` yields `null`.
- `cy.focused()` is a query, and it is _safe_ to chain further commands.

## Examples

### No Args

#### Get the element that is focused

```javascript
cy.focused().then(($el) => {
  // do something with $el
})
```

#### Blur the element with focus

```javascript
cy.focused().blur()
```

#### Make an assertion on the focused element

```javascript
cy.focused().should('have.attr', 'name', 'username')
```

#### Assert that no element has focus

```javascript
cy.focused().should('not.exist')
```

## Notes

### Focus on the document body

When the page's `<body>` is the document's active element, which is the
browser's default when nothing else has focus, `cy.focused()` treats the page
as having no focused element. Without a
[`.should('not.exist')`](#Assert-that-no-element-has-focus) assertion, the
command retries and then fails with
``Expected to find element: `focused`, but never found it.``

### Focus inside a shadow root

When the focused element is inside an open shadow root, `cy.focused()` yields
that element rather than its shadow host. It follows nested open shadow roots
to the innermost focused element, whether or not
[`includeShadowDom`](/app/references/configuration#Global) is enabled.

## Rules

<HeaderRequirements />

- `cy.focused()` requires being chained off of `cy`.

<HeaderAssertions />

- `cy.focused()` will automatically [retry](/app/core-concepts/retry-ability)
  until a focused element
  [exists in the DOM](/app/core-concepts/introduction-to-cypress#Implicit-Assertions).
- `cy.focused()` will automatically [retry](/app/core-concepts/retry-ability)
  until all chained assertions have passed.

<HeaderTimeouts />

- `cy.focused()` can time out waiting for a focused element to
  [exist in the DOM](/app/core-concepts/introduction-to-cypress#Implicit-Assertions).
- `cy.focused()` can time out waiting for assertions you've added to pass.
