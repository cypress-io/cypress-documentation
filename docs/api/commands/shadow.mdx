# shadow

Traverse into the shadow DOM of an element.

## Syntax

```javascript
.shadow()
.shadow(options)
```

### Usage

<Icon name="check-circle" color="green" /> **Correct Usage**

```javascript
cy.get('.shadow-host').shadow()
```

<Icon name="exclamation-triangle" color="red" /> **Incorrect Usage**

```javascript
cy.shadow() // Errors, cannot be chained off 'cy'
cy.task('log', 'hello').shadow() // Errors, 'task' does not yield DOM element
cy.get('.not-a-shadow-host').shadow() // Errors, subject must host a shadow root
cy.get('video').shadow() // Errors, the browser's own shadow roots are closed
```

### Arguments

<Icon name="angle-right" /> **options _(Object)_**

Pass in an options object to change the default behavior of `.shadow()`.

| Option    | Default                                                           | Description                                                                         |
| --------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `log`     | `true`                                                            | Displays the command in the [Command log](/app/core-concepts/open-mode#Command-Log) |
| `timeout` | [`defaultCommandTimeout`](/app/references/configuration#Timeouts) | Time to wait for `cy.get()` to resolve before [timing out](#Timeouts)               |

<HeaderYields />

- `.shadow()` yields the new DOM element(s) it found.
- `.shadow()` is a query, and it is _safe_ to chain further commands.

## Examples

### Find and click on a button inside the shadow DOM

```html
<div class="shadow-host">
  #shadow-root
  <button class="my-button">Click me</button>
</div>
```

```javascript
// yields [#shadow-root (open)]
cy.get('.shadow-host').shadow().find('.my-button').click()
```

## Notes

### Closed and user-agent shadow roots in `.shadow()`

`.shadow()` traverses open shadow roots, the kind a page creates with
`attachShadow({ mode: 'open' })`. To find a shadow root, `.shadow()` reads the
subject's
[`shadowRoot`](https://developer.mozilla.org/en-US/docs/Web/API/Element/shadowRoot)
property, and the browser returns `null` for two other kinds of shadow root:

- Closed shadow roots, which a page creates with
  `attachShadow({ mode: 'closed' })`
- User-agent shadow roots, which the browser builds to render elements such as
  `<video controls>`, `<audio controls>`, and `<input type="number">`

The browser
[keeps both kinds out of reach of JavaScript](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_shadow_DOM#encapsulation_from_javascript)
on the page, and Cypress queries the DOM with the same APIs your application's
scripts use. So `.shadow()` retries until it times out on an element like a
`<video>`, even though the browser's DevTools show a `#shadow-root (user-agent)`
inside it:

```text
Timed out retrying after 4000ms: Expected the subject to host a shadow root, but never found it.
```

The [`includeShadowDom`](/app/references/configuration#Global) option searches
open shadow roots only, too. A query with `includeShadowDom: true` doesn't find
elements inside a closed or user-agent shadow root, such as a media control's
pseudo-element.

To test an element that renders a user-agent shadow root, drive it the way your
application does: through the element's own properties and methods, or with
the keys a user presses.

```html title="index.html"
<video id="intro-video" src="intro.webm" controls muted></video>
<input id="quantity" type="number" value="1" />
```

```javascript title="spec.cy.js"
// the browser shows its media controls
cy.get('#intro-video').should('have.prop', 'controls', true)

// play the video without clicking the control's play button;
// .its(0) yields the <video> element, which has the play() method
cy.get('#intro-video').its(0).invoke('play')
cy.get('#intro-video').should('have.prop', 'paused', false)

// step the value up, as the spin button's up arrow does
cy.get('#quantity').type('{uparrow}')
cy.get('#quantity').should('have.value', '2')
```

For a closed shadow root in your own components, test what the component
exposes on its host element, such as its attributes, properties, and events.

## Rules

<HeaderRequirements />

- `.shadow()` requires being chained off a command that yields a DOM element
  that hosts an open shadow root directly. Closed and user-agent shadow roots
  [can't be traversed](#Closed-and-user-agent-shadow-roots-in-shadow).

<HeaderAssertions />

- `.shadow()` automatically [retries](/app/core-concepts/retry-ability)
  until the element(s)
  [exist in the DOM](/app/core-concepts/introduction-to-cypress#Implicit-Assertions).
- `.shadow()` automatically [retries](/app/core-concepts/retry-ability)
  until the element(s) host(s) a shadow root.
- `.shadow()` automatically [retries](/app/core-concepts/retry-ability)
  until all chained assertions have passed.

<HeaderTimeouts />

- `.shadow()` can time out waiting for the element(s) to
  [exist in the DOM](/app/core-concepts/introduction-to-cypress#Implicit-Assertions).
- `.shadow()` can time out waiting for the element(s) to host a shadow root.
- `.shadow()` can time out waiting for assertions you've added to pass.

## Known Issue

When working with `cy.click()`, it sometimes doesn't click the right element in
Chrome. The misclick happens because of
[the ambiguity in spec](https://bugs.chromium.org/p/chromium/issues/detail?id=1188919&q=shadowRoot%20elementFromPoint&can=2).

In this case, pass `'top'` to `cy.click()` like below:

```js
cy.get('#element').shadow().find('[data-test-id="my-button"]').click('top')
```
