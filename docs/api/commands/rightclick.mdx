# rightclick

Right click a DOM element to test custom context menus and other `contextmenu`
handling in your app.

:::caution

`.rightclick()` does not open context menus native to the browser. Use
`.rightclick()` to test your app's handling of right click events such as
`contextmenu`. To confirm your app suppresses the browser's own menu, see
[Check that your app blocks the native context menu](#Check-that-your-app-blocks-the-native-context-menu).

:::

## Syntax

```javascript
.rightclick()
.rightclick(options)
.rightclick(position)
.rightclick(position, options)
.rightclick(x, y)
.rightclick(x, y, options)
```

### Usage

<Icon name="check-circle" color="green" /> **Correct Usage**

```javascript
cy.get('[data-cy=file-row]').first().rightclick() // Right click on the first file row
cy.focused().rightclick() // Right click on el with focus
cy.contains('Today').rightclick() // Right click on first el containing 'Today'
```

<Icon name="exclamation-triangle" color="red" /> **Incorrect Usage**

```javascript
cy.rightclick('[data-cy=file-row]') // Errors, cannot be chained off 'cy'
cy.window().rightclick() // Errors, 'window' does not yield DOM element
```

### Arguments

<Icon name="angle-right" /> **position _(String)_**

The position where the right click should be issued. The `center` position is
the default position. Valid positions are `topLeft`, `top`, `topRight`, `left`,
`center`, `right`, `bottomLeft`, `bottom`, and `bottomRight`.

<DocsImage
  src="/img/api/coordinates-diagram.svg"
  alt="Diagram of the nine positions on an element's border box: topLeft, top, and topRight along the top edge; left, center, and right across the middle; and bottomLeft, bottom, and bottomRight along the bottom edge. Edge and corner positions sit just inside the outer edge of the border box, on the border when the element has one, and never in the margin. center is the default."
  noBorder
/>

<Icon name="angle-right" /> **x _(Number)_**

The distance in pixels from the element's left to issue the right click.

<Icon name="angle-right" /> **y _(Number)_**

The distance in pixels from the element's top to issue the right click.

<Icon name="angle-right" /> **options _(Object)_**

Pass in an options object to change the default behavior of `.rightclick()`.

| Option                       | Default                                                                     | Description                                                                                                                                                                                                                     |
| ---------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `altKey`                     | `false`                                                                     | Activates the alt key (option key for Mac). Aliases: `optionKey`.                                                                                                                                                               |
| `animationDistanceThreshold` | [`animationDistanceThreshold`](/app/references/configuration#Actionability) | The distance in pixels an element must exceed over time to be [considered animating](/app/core-concepts/interacting-with-elements#Animations).                                                                                  |
| `ctrlKey`                    | `false`                                                                     | Activates the control key. Aliases: `controlKey`.                                                                                                                                                                               |
| `force`                      | `false`                                                                     | Forces the action, disables [waiting for actionability](#Assertions).                                                                                                                                                           |
| `log`                        | `true`                                                                      | Displays the command in the [Command Log](/app/core-concepts/open-mode#Command-Log).                                                                                                                                            |
| `metaKey`                    | `false`                                                                     | Activates the meta key (Windows key or command key for Mac). Aliases: `commandKey`, `cmdKey`.                                                                                                                                   |
| `multiple`                   | `false`                                                                     | Serially right click multiple elements.                                                                                                                                                                                         |
| `scrollBehavior`             | [`scrollBehavior`](/app/references/configuration#Actionability)             | Viewport position to where an element [should be scrolled](/app/core-concepts/interacting-with-elements#Scrolling) before executing the command. Accepts a single alignment, a per-axis `{ block, inline }` object, or `false`. |
| `shiftKey`                   | `false`                                                                     | Activates the shift key.                                                                                                                                                                                                        |
| `timeout`                    | [`defaultCommandTimeout`](/app/references/configuration#Timeouts)           | Time to wait for `.rightclick()` to resolve before [timing out](#Timeouts).                                                                                                                                                     |
| `waitForAnimations`          | [`waitForAnimations`](/app/references/configuration#Actionability)          | Whether to wait for elements to [finish animating](/app/core-concepts/interacting-with-elements#Animations) before executing the command.                                                                                       |

<HeaderYields />

- `.rightclick()` yields the same subject it was given.
- It is [unsafe](/app/core-concepts/retry-ability#Only-queries-are-retried)
  to chain further commands that rely on the subject after `.rightclick()`.

## Examples

### Context menus

#### Open a custom context menu

Chaining further commands off the subject of `.rightclick()` is unsafe, since
opening a menu can re-render the element. Start a new chain from `cy` and assert
that the menu appeared.

```javascript
cy.get('[data-cy=file-row]').first().rightclick()
cy.get('[data-cy=context-menu]').should('be.visible')
```

#### Choose an item from a context menu

Query the menu from `cy`, not from the subject of `.rightclick()`, then click
the item you want.

```javascript
cy.get('[data-cy=file-row]').first().rightclick()
cy.get('[data-cy=context-menu]').contains('Rename').click()
cy.get('[data-cy=rename-input]').should('be.focused')
```

#### Close a context menu

Test the way your users close the menu. Many menus close when the user presses
Escape.

```javascript
cy.get('[data-cy=file-row]').first().rightclick()
cy.get('[data-cy=context-menu]').should('be.visible')
cy.get('body').type('{esc}')
cy.get('[data-cy=context-menu]').should('not.exist')
```

#### Check that your app blocks the native context menu

`.rightclick()` never opens the browser's own context menu, so a test can pass
even when your app forgets to call `preventDefault()` and real users see two
menus. To check, add a `contextmenu` listener on the window after the page
loads. It runs after your app's own handlers, so the event it receives shows
whether one of them called `preventDefault()`.

```javascript
cy.window().then((win) => {
  win.addEventListener('contextmenu', cy.stub().as('contextmenu'))
})
cy.get('[data-cy=canvas]').rightclick()
cy.get('@contextmenu').should('have.been.calledWithMatch', {
  defaultPrevented: true,
})
```

If your app stops the event from propagating, the window listener never runs.
Assert on your app's menu instead.

### Position

#### Specify a corner of the element to right click

Right click the top right corner of the DOM element.

```javascript
cy.get('[data-cy=file-row]').first().rightclick('topRight')
```

### Coordinates

#### Specify explicit coordinates relative to the top left corner

The right click below is issued inside of the element (15px from the left and
40px from the top).

```javascript
cy.get('[data-cy=chart]').rightclick(15, 40)
```

#### Right click a point on a canvas or chart

When the target is a region inside one element, such as a bar in a chart drawn
on a `<canvas>`, there is no child element to select. Pass the coordinates of
that spot instead.

```javascript
// the March bar is 120px from the left and 45px from the top of the chart
cy.get('[data-cy=chart]').rightclick(120, 45)
cy.get('[data-cy=context-menu]').should('contain', 'March')
```

When a coordinate right click lands in the wrong place, click the `rightclick`
command in the Command Log to pin its snapshot. A red dot marks the exact point
Cypress right clicked.

<DocsImage
  src="/img/api/rightclick/command-log-rightclick-chart-snapshot.png"
  alt="The rightclick 120, 45 command pinned in the Command Log. In the app preview, a red dot marks the right click on the March bar of a bar chart, and the app's context menu shows Show March details and Hide March."

### Options

#### Control where Cypress scrolls the element before right clicking

Cypress scrolls the element into view before right clicking it. To put the
element in a predictable spot, such as clear of a sticky header, pass
`scrollBehavior`. Center the element in the viewport, or set each axis
separately with a `{ block, inline }` object.

```javascript
cy.get('[data-cy=row-42]').rightclick({ scrollBehavior: 'center' })
cy.get('[data-cy=carousel-item]').rightclick({
  scrollBehavior: { block: 'center', inline: 'nearest' },
})
```

#### Dismiss what covers an element before right clicking it

When another element covers the one you want to right click, deal with it the
way a user would before reaching for
[`{ force: true }`](#Force-a-right-click-regardless-of-its-actionable-state).
Forcing skips the checks that would catch a real bug, such as a banner that
blocks users from opening the menu.

```javascript
cy.get('[data-cy=cookie-banner] [data-cy=accept]').click()
cy.get('[data-cy=file-row]').first().rightclick()
```

#### Force a right click regardless of its actionable state

Forcing a right click overrides the
[actionable checks](/app/core-concepts/interacting-with-elements#Forcing)
Cypress applies and fires the events at the element.

```javascript
cy.get('[data-cy=file-row]').first().rightclick({ force: true })
```

#### Force a right click with position argument

```javascript
cy.get('[data-cy=file-row]').first().rightclick('bottomLeft', { force: true })
```

#### Force a right click with relative coordinates

```javascript
cy.get('[data-cy=file-row]').first().rightclick(5, 10, { force: true })
```

#### Right click every element that matches a selector

By default, Cypress errors if you try to right click multiple elements. When
you pass `{ multiple: true }`, Cypress right clicks each element in turn and
logs each right click to the
[Command Log](/app/core-concepts/open-mode#Command-Log).

```javascript
cy.get('[data-cy=file-row]').rightclick({ multiple: true })
```

#### Right click with key combinations

Pass a modifier key option to hold that key while right clicking, such as
`altKey` for Alt + right click. The [options table](#Arguments) lists each
modifier key option and its aliases.

:::info

You can also use key combinations during [.type()](/api/commands/type). This
offers options to hold down keys across multiple commands. See
[Key Combinations](/api/commands/type#Key-Combinations) for more information.

:::

#### Command right click

```js
// execute a CMD + right click on the first file
cy.get('[data-cy=file-row]').first().rightclick({
  metaKey: true,
})
```

#### Shift right click to show more options

Some apps add options to the context menu when the user holds Shift while right
clicking.

```js
// execute a SHIFT + right click on the first file
cy.get('[data-cy=file-row]').first().rightclick({
  shiftKey: true,
})
cy.get('[data-cy=context-menu]').should('contain', 'Copy as path')
```

## Notes

### Actionability

#### The element must first reach actionability

`.rightclick()` is an "action command" that follows all the rules of
[Actionability](/app/core-concepts/interacting-with-elements).

### Events

#### Events fired by a right click

Cypress first moves the mouse to the element, which fires hover events such as
`pointerover`, `mouseover`, and `mousemove`. Then `.rightclick()` fires these
events in order:

1. `pointerdown`
2. `mousedown`
3. `contextmenu`
4. `pointerup`
5. `mouseup`

Each event carries `button: 2` and `buttons: 2`. `.rightclick()` does not fire a
`click` event.

The diagram compares the sequence with `.click()` and shows which events
Cypress skips when `pointerdown` is cancelled.

<DocsImage
  src="/img/api/rightclick/rightclick-event-sequence.svg"
  alt="Three event sequences. .click() fires pointerdown, mousedown, pointerup, mouseup, then click. .rightclick() fires pointerdown, mousedown, contextmenu, pointerup, then mouseup, and no click event. When pointerdown is cancelled, .rightclick() fires pointerdown, contextmenu, then pointerup, and skips mousedown and mouseup."
  noBorder
/>

### Right click on macOS with the control key

#### Ctrl + click does not fire a `contextmenu` event

On macOS, users can open a context menu by holding Control and clicking.
`.click({ ctrlKey: true })` fires a `click` event with the control key held, not
a `contextmenu` event. To test the context menu a Ctrl + click opens, use
`.rightclick()`.

### Right click or trigger a contextmenu event

#### Choose between .rightclick() and .trigger('contextmenu')

Both commands wait for the element to reach an
[actionable state](/app/core-concepts/interacting-with-elements).

- `.rightclick()` fires the full sequence of
  [events fired by a right click](#Events-fired-by-a-right-click) and gives
  focus to the element, the way a user's right click does.
- [`.trigger('contextmenu')`](/api/commands/trigger) fires only the
  `contextmenu` event and leaves focus where it was. Use it when you need that
  single event, or to set event properties that `.rightclick()` does not
  expose.

### Focus

#### Focus is given to the first focusable element

Like [`.click()`](/api/commands/click#Focus), `.rightclick()` gives focus to the
first focusable element at the click coordinates or among its ancestors.

### Cancellation

#### Pointerdown or mousedown cancellation prevents focus

If the `pointerdown` or `mousedown` event has its default action prevented
(`e.preventDefault()`), Cypress does not give the element focus.

When `pointerdown` is cancelled, Cypress also skips the `mousedown` and
`mouseup` events, following the Pointer Events spec. It still sends
`contextmenu` and `pointerup`.

Cancelling the `contextmenu` event does not change which events Cypress sends.

## Rules

<HeaderRequirements />

- `.rightclick()` requires being chained off a command that yields DOM
  element(s).
- `.rightclick()` requires a single element unless you pass
  `{ multiple: true }`.
- `.rightclick()` cannot be called on a `<select>` element. Use
  [`.select()`](/api/commands/select) to change its value.

<HeaderAssertions />

- `.rightclick()` automatically waits for the element to reach an
  [actionable state](/app/core-concepts/interacting-with-elements).
- `.rightclick()` itself is not retried. It fires once when the element is
  actionable. Assertions chained after `.rightclick()` are retried until they
  pass or time out. See
  [Only queries are retried](/app/core-concepts/retry-ability#Only-queries-are-retried).

<HeaderTimeouts />

- `.rightclick()` can time out waiting for the element to reach an
  [actionable state](/app/core-concepts/interacting-with-elements).
- `.rightclick()` can time out waiting for assertions you've added to pass.
