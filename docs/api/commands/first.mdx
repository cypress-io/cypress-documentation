# first

Get the first DOM element within a set of DOM elements.

:::info

The querying behavior of this command matches exactly how
[`.first()`](https://api.jquery.com/first) works in jQuery.

:::

## Syntax

```javascript
.first()
.first(options)
```

### Usage

<Icon name="check-circle" color="green" /> **Correct Usage**

```javascript
cy.get('nav a').first() // Yield first link in nav
```

<Icon name="exclamation-triangle" color="red" /> **Incorrect Usage**

```javascript
cy.first() // Errors, cannot be chained off 'cy'
cy.getCookies().first() // Errors, 'getCookies' does not yield DOM element
```

### Arguments

<Icon name="angle-right" /> **options _(Object)_**

Pass in an options object to change the default behavior of `.first()`.

| Option    | Default                                                           | Description                                                                         |
| --------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `log`     | `true`                                                            | Displays the command in the [Command log](/app/core-concepts/open-mode#Command-Log) |
| `timeout` | [`defaultCommandTimeout`](/app/references/configuration#Timeouts) | Time to wait for `.first()` to resolve before [timing out](#Timeouts)               |

<HeaderYields />

- `.first()` yields the first DOM element within the set it was given.
- `.first()` is a query, and it is _safe_ to chain further commands.

## Examples

### No Args

#### Get the first list item in a list

```html
<ul>
  <li class="one">Knick knack on my thumb</li>
  <li class="two">Knick knack on my shoe</li>
  <li class="three">Knick knack on my knee</li>
  <li class="four">Knick knack on my door</li>
</ul>
```

```javascript
// yields <li class="one">Knick knack on my thumb</li>
cy.get('li').first()
```

## Notes

### Selecting the first element that matches a selector

`.first()` takes no selector. Cypress passes the call straight to jQuery's
`.first()`, which ignores any arguments, so `cy.get('li').first('.active')`
yields the first `<li>` whether or not it has the class `active`. To get the
first element that matches a selector, narrow the set with
[`.filter()`](/api/commands/filter) before calling `.first()`.

```javascript
cy.get('li').filter('.active').first()
```

## Rules

<HeaderRequirements />

- `.first()` requires being chained off a command that yields DOM element(s) or
  a document.

<HeaderAssertions />

- `.first()` will automatically [retry](/app/core-concepts/retry-ability)
  until the element(s)
  [exist in the DOM](/app/core-concepts/introduction-to-cypress#Implicit-Assertions).
- `.first()` will automatically [retry](/app/core-concepts/retry-ability)
  until all chained assertions have passed.

<HeaderTimeouts />

- `.first()` can time out waiting for the element(s) to
  [exist in the DOM](/app/core-concepts/introduction-to-cypress#Implicit-Assertions).
- `.first()` can time out waiting for assertions you've added to pass.
