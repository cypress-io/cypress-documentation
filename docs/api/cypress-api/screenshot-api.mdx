# Cypress.Screenshot

The Screenshot API sets the defaults for how screenshots are captured
during [.screenshot](/api/commands/screenshot) and automatic screenshots taken
during test failures. You can set defaults for the following:

- Which parts of the screen to capture.
- Whether to scale your application under test in the screenshot.
- Whether to disable JavaScript timers and CSS animations when taking the
  screenshot.
- Whether to automatically take screenshots when there are run failures.
- Which, if any, elements to black out when taking the screenshot.
- Whether to wait for the Command Log to synchronize before taking the
  screenshot.

## Syntax

```javascript
Cypress.Screenshot.defaults(options)
```

### Arguments

<Icon name="angle-right" /> **options _(Object)_**

An object containing one or more of the following:

| Option                       | Default      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `blackout`                   | `[]`         | Array of string selectors used to match elements that should be blacked out when the screenshot is taken. Does not apply to `runner` captures.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `capture`                    | `'fullPage'` | Which parts of the Cypress Test Runner to capture. Cypress ignores this value for element screenshot captures. Valid values are `viewport`, `fullPage`, or `runner`. When `viewport`, Cypress captures your application under test in the current viewport. When `fullPage`, Cypress captures your application under test in its entirety from top to bottom. When `runner`, Cypress captures the entire browser viewport, including the Cypress Command Log. For screenshots automatically taken on test failure, Cypress always coerces capture to `runner`. When [Test Replay](/cloud/features/test-replay) is enabled and the Runner UI is hidden, a `runner` screenshot does not include the Runner UI and instead captures the application under test only in the current viewport. |
| `disableTimersAndAnimations` | `true`       | When true, prevents JavaScript timers (`setTimeout`, `setInterval`, etc) and CSS animations from running while the screenshot is taken.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `onAfterScreenshot`          | `null`       | A callback Cypress calls right after it takes a screenshot, including the screenshots it takes automatically when a test fails. For an element capture, the first argument is the element being captured. For other screenshots, the first argument is the jQuery-wrapped `<html>` element. The second argument holds the screenshot's properties, such as the absolute `path` Cypress saved it to, its `dimensions`, and `testFailure`, which is `true` when Cypress took the screenshot because a test failed.                                                                                                                                                                                                                                                                          |
| `onBeforeScreenshot`         | `null`       | A callback Cypress calls right before it takes a screenshot, including the screenshots it takes automatically when a test fails. For an element capture, the argument is the element being captured. For other screenshots, the argument is the jQuery-wrapped `<html>` element.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `overwrite`                  | `false`      | Whether to overwrite duplicate screenshot files with the same file name when saving.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `scale`                      | `false`      | Whether to scale the app to fit into the browser viewport. Cypress always coerces `scale` to `true` for `runner` captures.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `screenshotOnRunFailure`     | `true`       | When true, automatically takes a screenshot when there is a failure during `cypress run`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## Examples

### Blackout elements before screenshot

Cypress blacks out elements that match the specified selectors from the
screenshot, but only when the `capture` option is `viewport`. Cypress ignores
`blackout` if `capture` option is `runner`.

```javascript
Cypress.Screenshot.defaults({
  blackout: ['.secret-info', '[data-hide=true]'],
})
```

### Take a screenshot of the entire Cypress browser window

By default, [`cy.screenshot()`](/api/commands/screenshot) only captures your
application under test. You may want it to capture the entire Cypress browser
for debugging purposes.

```javascript
Cypress.Screenshot.defaults({
  capture: 'runner',
})
```

### Allow timers and animations to keep running

By default, Cypress disables JavaScript timers and CSS animations to try to
prevent changes to your application under test while the screenshot is taken, but you
can turn off this behavior.

```javascript
Cypress.Screenshot.defaults({
  disableTimersAndAnimations: false,
})
```

### Disable screenshots on run failures

By default, Cypress automatically takes a screenshot when there is a failure
when running `cypress run`, but you can disable this.

```javascript
Cypress.Screenshot.defaults({
  screenshotOnRunFailure: false,
})
```

### Overwrite existing screenshots

By default, Cypress saves unique screenshot files for every screenshot that is
taken within the same test. You can choose to overwrite existing screenshots
with the same file name using the `overwrite` option.

```javascript
Cypress.Screenshot.defaults({
  overwrite: true,
})
```

### Scale `viewport` and `fullPage` captures

By default, Cypress turns off scaling the application under test when the
`capture` option is `viewport` to prevent differences between screenshots on
screens with different resolutions. You can turn scaling on and have your app
scaled like it is during normal use of Cypress. Cypress always coerces `scale` to
`true` if the `capture` option is `runner`.

```javascript
Cypress.Screenshot.defaults({
  scale: true,
})
```

### Change the DOM using `onBeforeScreenshot` and `onAfterScreenshot`

The `onBeforeScreenshot` and `onAfterScreenshot` callbacks provide an
opportunity to synchronously change the DOM to create a more consistent state
for the screenshot.

In this example, imagine there is a clock in your app showing the current time.
The changing clock can cause screenshots to be non-deterministic, which could create false
negatives when screenshot diffing. You can use `onBeforeScreenshot` to hide the
clock and then show it again with `onAfterScreenshot`.

```javascript
Cypress.Screenshot.defaults({
  onBeforeScreenshot($el) {
    const $clock = $el.find('.clock')

    if ($clock) {
      $clock.hide()
    }
  },

  onAfterScreenshot($el, props) {
    const $clock = $el.find('.clock')

    if ($clock) {
      $clock.show()
    }
  },
})
```

### Get properties from the `onAfterScreenshot` callback

```javascript
Cypress.Screenshot.defaults({
  onAfterScreenshot($el, props) {
    // props has information about the screenshot,
    // including but not limited to the following:
    // {
    //   blackout: [],
    //   dimensions: {
    //     height: 720,
    //     width: 1280,
    //   },
    //   duration: 2300, // in milliseconds
    //   path: '/Users/janelane/project/cypress/screenshots/login.cy.js/Login -- shows an error (failed).png',
    //   scaled: true,
    //   size: 58607, // in bytes
    //   specName: 'login.cy.js',
    //   takenAt: '2026-11-01T17:00:00.000Z',
    //   testAttemptIndex: 0,
    //   testFailure: true, // only on screenshots taken because a test failed
    // }
  },
})
```

### Attach failure screenshots to a mochawesome report

When a test fails during `cypress run`, Cypress takes a screenshot and passes its
properties to the default `onAfterScreenshot` callback with `testFailure` set to
`true`. The callback runs before Cypress emits the test's
[`test:after:run`](/api/cypress-api/catalog-of-events#Cypress-Events) event, so
a `test:after:run` handler can attach the screenshot Cypress saved to an HTML
report.

The `path` property is the absolute path Cypress saved the screenshot to. Read
the path from the callback rather than rebuilding it from `Cypress.spec` and the
test's titles: Cypress removes characters such as `:` from titles in file names,
and the folders between the screenshots folder and the image change with the
[common ancestor of the specs in the run](/app/core-concepts/writing-and-organizing-tests#How-asset-file-paths-are-generated).

This support file adds each failure screenshot to the failed test in a
[mochawesome](https://www.npmjs.com/package/mochawesome) report with
`addContext()`:

```javascript title="cypress/support/e2e.js"
import addContext from 'mochawesome/addContext'

let failureScreenshotPath

Cypress.Screenshot.defaults({
  onAfterScreenshot($el, props) {
    if (props.testFailure) {
      failureScreenshotPath = props.path
    }
  },
})

Cypress.on('test:after:run', (test) => {
  if (failureScreenshotPath) {
    // The path inside the screenshots folder, with forward slashes
    const relativePath = failureScreenshotPath
      .slice(Cypress.config('screenshotsFolder').length + 1)
      .replaceAll('\\', '/')
    const url = relativePath.split('/').map(encodeURIComponent).join('/')

    addContext({ test }, `../screenshots/${url}`)
  }

  failureScreenshotPath = undefined
})
```

The example assumes the report is written to a folder next to the
[`screenshotsFolder`](/app/references/configuration#Screenshots), such as
`cypress/reports` beside the default `cypress/screenshots`, so
`../screenshots/` reaches the image from the report. Change the prefix to match
where your report lives.

Keep these behaviors in mind:

- Cypress takes failure screenshots only during `cypress run`, and only while
  `screenshotOnRunFailure` is `true`.
- A failure in a `beforeEach` hook produces a screenshot for the test the hook
  ran for.
- With [test retries](/app/guides/test-retries), Cypress takes a screenshot and
  emits `test:after:run` for each failed attempt, so each attempt gets its own
  screenshot.
