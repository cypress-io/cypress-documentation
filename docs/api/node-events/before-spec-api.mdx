# Before Spec Event

The `before:spec` event fires before Cypress runs a spec file. When running cypress
via `cypress open`, the event fires when the browser launches.

## Syntax

<WarningSetupNodeEvents />

:::caution

⚠️ When running via `cypress open`, the `before:spec` event only fires if the
[experimentalInteractiveRunEvents flag](/app/references/configuration#Experiments)
is enabled.

:::

:::cypress-config-plugin-example

```js
on('before:spec', (spec) => {
  /* ... */
})
```

:::

## Usage

You can return a promise from the `before:spec` event handler and Cypress
awaits it before proceeding to run the spec.

### Log the relative spec path to stdout before the spec is run

:::cypress-config-plugin-example

```ts
on('before:spec', (spec) => {
  // spec will look something like this:
  // {
  //   name: 'login.cy.js',
  //   relative: 'cypress/e2e/login.cy.js',
  //   absolute: '/Users/janelane/app/cypress/e2e/login.cy.js',
  // }
  console.log('Running', spec.relative)
})
```

:::
