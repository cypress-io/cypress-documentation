# Changelog

Cypress Cloud is a continuously delivered service, so new features and
improvements ship on an ongoing basis rather than as discrete versioned
downloads. Release notes for Cypress Cloud — alongside those for the Cypress
App, [UI Coverage](/ui-coverage/get-started/introduction), and
[Cypress Accessibility](/accessibility/get-started/introduction) — are published
on the Cypress releases page.

See the latest Cypress Cloud updates, each with its release date and a summary
of what changed, on the releases page.
