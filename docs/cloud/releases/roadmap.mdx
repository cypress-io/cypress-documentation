# Roadmap

The Cypress roadmap gives you a transparent view of what is coming next across
the Cypress platform, including Cypress Cloud. Initiatives are organized by
status:

- **Building**: actively in development.
- **Planned**: committed and scheduled, but not yet started.
- **Evaluating**: under consideration, with priority and direction still being
  shaped.

See what is coming next for Cypress Cloud on the roadmap. It also links to a
**Recently shipped** section for features that have already been released.
