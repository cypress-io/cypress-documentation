# Project Analytics & Insights

Cypress Cloud provides Analytics to offer insight into metrics like runs over
time, run duration and visibility into tests suite size over time.

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-overview.png"
  alt="Cloud Analytics Screenshot"
/>

## Run status

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-runs-over-time.png"
  alt="Cloud Analytics Runs Over Time Screenshot"
/>

This report shows the number of runs your organization has recorded to Cypress
Cloud, broken down by the final status of the run. Each run represents a single
invocation of `cypress run --record` for this project, whether in CI or on a
local machine.

### Filters

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-runs-over-time-filters.png"
  alt="Cloud Analytics Runs Over Time Filters Screenshot"
/>

Results may be filtered by:

- Branch
- Time Range
- Time Interval (Hourly, Daily, Weekly, Monthly, Quarterly)

### Results

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-runs-over-time-graph.png"
  alt="Cloud Analytics Runs Over Time Graph Screenshot"
/>

The total runs over time are displayed for passed, failed, running, timed out,
and errored tests, respective of the filters selected.

The results may be downloaded as a comma-separated values (CSV) file for further
analysis.

This can be done via the download icon to the right of the filters.

### Key Performance Indicators

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-runs-over-time-kpi.png"
  alt="Cloud Analytics Runs Over Time KPI Screenshot"
/>

Total runs, average per day, passed runs, and failed runs are the computed
respective of the filters selected.

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-runs-over-time-table.png"
  alt="Cloud Analytics Runs Over Time Table Screenshot"
/>

A table of results grouped by date for the time range filter is displayed with
passed, failed, running, timed out, and errored columns.

## Run duration

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-run-duration.png"
  alt="Cloud Analytics Run Duration Screenshot"
/>

This report shows the average duration of a Cypress run for your project,
including how test parallelization is impacting your total run time.
We only include passing runs here — failing or errored runs can sway the average
away from its typical duration.

### Filters

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-run-duration-filters.png"
  alt="Cloud Analytics Run Duration Filters Screenshot"
/>

Results may be filtered by:

- Branch
- Tag
- Time Range
- Time Interval (Hourly, Daily, Weekly, Monthly, Quarterly)

### Results

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-run-duration-graph.png"
  alt="Cloud Analytics Run Duration Graph Screenshot"
/>

The average run duration over time is displayed respective of the filters
selected.

The results may be downloaded as a comma-separated values (CSV) file for further
analysis. This can be done via the download icon to the right of the filters.

### Key Performance Indicators

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-run-duration-kpi.png"
  alt="Cloud Analytics Run Duration KPI Screenshot"
/>

Average parallelization, average run duration and time saved from
parallelization are computed respective of the filters selected.

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-run-duration-table.png"
  alt="Cloud Analytics Run Duration Table Screenshot"
/>

A table of results grouped by date for the time range filter is displayed with
average runtime, concurrency, and time saved from parallelization columns.

## Test suite size

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-test-suite-size.png"
  alt="Cloud Analytics Test Suite Size Screenshot"
/>

This report shows how your test suite is growing over time. It calculates the
average number of test cases executed per run for each day in the given time
period. It excludes runs that errored or timed out since they don't accurately
represent the size of your test suite.

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-test-suite-size-filters.png"
  alt="Cloud Analytics Test Suite Size Filters Screenshot"
/>

Results may be filtered by:

- Branch
- Tag
- Time Range
- Time Interval (Hourly, Daily, Weekly, Monthly, Quarterly)

### Results

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-test-suite-size-graph.png"
  alt="Cloud Analytics Test Suite Size Graph Screenshot"
/>

The average test suite size over time is displayed respective of the filters
selected.

The results may be downloaded as a comma-separated values (CSV) file for further
analysis. This can be done via the download icon to the right of the filters.

### Key Performance Indicators

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-test-suite-size-kpi.png"
  alt="Cloud Analytics Test Suite Size KPI Screenshot"
/>

Unique tests and number of spec files are computed respective of the filters

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-test-suite-size-table.png"
  alt="Cloud Analytics Test Suite Size Table Screenshot"

## Top failures

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-top-failures.png"
  alt="Cloud Analytics Top Failures Screenshot"
/>

This report shows the top failures in your test suite.

### Filters and Views

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-top-failures-filters.png"
  alt="Cloud Analytics Top Failures Filters Screenshot"
/>

Results can be seen through custom grouping by using the "View By" dropdown. It
can be grouped by:

- Test Case
- Spec File
- Tag
- Branch

Results may also be filtered by:

- Branch
- Tag
- Time Range
- Run Group
- Committer
- Spec File
- Browser
- Cypress Version
- Operating System

### Results

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-top-failures-graph.png"
  alt="Cloud Analytics Top Failures Graph Screenshot"
/>

The number of tests by failure rate is displayed respective of the filters
selected.

The results may be downloaded as a comma-separated values (CSV) file for further
analysis.

This can be done via the download icon to the right of the filters.

### Key Performance Indicators

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-top-failures-kpi.png"
  alt="Cloud Analytics Top Failures KPI Screenshot"
/>

The main key performance indicators tracked are:

- Median failure rate
- Number of failures (measured by test cases)

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-top-failures-table.png"
  alt="Cloud Analytics Top Failures Table Screenshot"
/>

A table of results grouped by failure rate is displayed with spec files and
total runs.

### Test details

Selecting a test in the table opens a drill-in panel with context for triaging
that failure, including error history and links to recorded runs. When
[Cloud AI](/cloud/faq#What-is-Cloud-AI) is enabled for your organization, the
panel also includes a collapsible **Test intent** section: the same
[Test Intent Summary](/cloud/features/cypress-ai-features#Test-Intent-Summaries)
as in the test details sidebar. Cypress generates it on first open from the
test's latest failure within your current branch and time range filters.

## Flaky tests

:::tip

**Cypress Cloud Feature:** Flaky test analytics are available to organizations with a
[Team Cypress Cloud plan](https://cypress.io/pricing).

:::

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-flaky-tests.png"
  alt="Flaky tests analytics in Cypress Cloud with a chart of flaky test cases per day, severity KPIs, and a filterable table of flaky tests"
/>

This report shows flaky tests in your suite so you can track reliability trends
and prioritize fixes by severity. For how Cypress detects flake, alerts your
team, and integrates with CI, see
[Flaky Test Management](/cloud/features/flaky-test-management).

### Filters and Views

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-flaky-tests-filters.png"
  alt="Flaky tests analytics View By and Filter By controls for branch, tag, time range, run group, spec file, browser, Cypress version, and operating system"
/>

Results can be seen through custom grouping by using the **View By** dropdown.
It can be grouped by:

- Test Case
- Spec File
- Tag
- Branch

Results may also be filtered by:

- Branch
- Tag
- Time Range
- Run Group
- Spec File
- Browser
- Cypress Version
- Operating System

### Results

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-flaky-tests-graph.png"
  alt="Flaky tests analytics chart of flaky test cases detected per day"
/>

The number of flaky test cases detected per day is displayed respective of the
filters selected.

The results may be downloaded as a comma-separated values (CSV) file for further
analysis. This can be done via the download icon to the right of the filters.

### Key Performance Indicators

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-flaky-tests-kpi.png"
  alt="Flaky tests analytics KPIs for overall flakiness and flaky test cases by high, medium, and low severity"
/>

The main key performance indicators tracked are:

- Overall flakiness (test cases)
- Number of flaky test cases by severity (high, medium, and low)

<DocsImage
  src="/img/cloud/features/analytics/dashboard-analytics-flaky-tests-table.png"
  alt="Flaky tests analytics table listing test cases with last flaky time, flaky rate, and severity"
/>

A table of flaky test cases is displayed with last flaky time, flaky rate, and
severity. See [Flake severity](/cloud/features/flaky-test-management#Flake-severity)
for how Cypress calculates severity from flake rate.

### Test details

Selecting a flaky test in the table opens a drill-in panel with context for
triaging that test, including flaky run history and error trends. When
[Cloud AI](/cloud/faq#What-is-Cloud-AI) is enabled for your organization, the
panel also includes a collapsible **Test intent** section: the same
[Test Intent Summary](/cloud/features/cypress-ai-features#Test-Intent-Summaries)
as in the test details sidebar. Cypress generates it on first open from the
test's latest flaky result within your current branch and time range filters.
